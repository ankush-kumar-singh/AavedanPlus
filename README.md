
# Aavedan+ AI Agent

An AI-powered citizen-service assistant designed to help users complete government application processes end-to-end with document validation, form assistance, consent-based submission, status tracking, failure recovery, and human escalation.

## 🚀 Project Overview

**Aavedan+** helps citizens apply for government services through a conversational AI agent instead of manually navigating complicated application processes.

The current prototype focuses on **Income Certificate** applications while the architecture supports additional services such as:

* Income Certificate
* Caste Certificate
* Residence Certificate
* EWS Certificate
* Birth Certificate
* Scholarship Applications

The system is designed for a hackathon/demo environment with a **local AI model** and a  **mock government portal** .

## 📄 Document Intelligence

The system supports document collection and validation before submission.

For the Income Certificate demo, the required documents include:

* Aadhaar / Identity document
* Salary Slip / Income proof
* Self Declaration

The system:

1. Checks whether required documents are available.
2. Validates the documents.
3. Extracts relevant information.
4. Uses the extracted information for form filling.
5. Prevents submission when required documents are missing or invalid.

The project also contains document-trust components for extraction, matching, OCR and validation.

## 🔐 Consent & Accountability

Aavedan+ does  **not automatically submit an application** .

Before submission:

1. The application information is prepared.
2. The user is shown the submission step.
3. Explicit consent is required.
4. Only after confirmation does the agent submit the application.

# 🧠 Design Principles

Aavedan+ follows these principles:

* **Local-first AI**
* **User-controlled actions**
* **Explicit consent**
* **Document validation before submission**
* **No fabricated government requirements**
* **Auditability**
* **Failure recovery**
* **Human escalation**
* **Persistent application tracking**
* **Modular service architecture**
* **Government-portal simulation for safe demonstration**
